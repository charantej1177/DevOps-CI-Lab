# DevOps CI Lab

## Project Title
Automate Build and Testing Processes Using CI Pipelines.

## Aim
To automate the build and testing process
using GitHub Actions.

## Technologies Used
- Python
- Git
- GitHub
- GitHub Actions
- VS Code

## Project Description
This project implements a Python calculator
with automated unit testing.

GitHub Actions automatically checks the
Python code and executes test cases whenever
code is pushed to the repository.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Automated Testing
- Continuous Integration

## Execution

Run the application:

python calculator.py

Run automated tests:

python -m unittest -v

## Result
Successfully implemented a CI pipeline
using GitHub Actions.
